# City job photos

Drop real install photos into a folder named after the city page's slug, e.g.

    attached_assets/cities/bellevue/front-roofline.jpg
    attached_assets/cities/kirkland/warm-white-wreath.webp

City pages pick these up automatically (first 3 per city, sorted by file name) and
show them under "Recent installs in {City}". Cities without photos fall back to a
rotating set of gallery photos. Keep files under ~300 KB (800-1200 px wide WebP is ideal).

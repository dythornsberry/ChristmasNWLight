# Christmas Northwest Web Colors

Reference: the existing truck-wrap artwork, `1500_16_02.ai`.
The blue/teal values below are web adaptations, not certified print swatches.

Use the shared tokens in `client/src/index.css` and Tailwind `brand` colors.

| Token | Role |
| --- | --- |
| `primary` | Existing Christmas red: quote buttons, pricing, form selections |
| `brand-blue` | Deep wrap-inspired blue: booking strip, footer, callout headings |
| `brand-teal` | Supporting navigation, links, and information icons on light backgrounds |
| `brand-soft` | Pale blue-tinted backgrounds for included services and quote callouts |
| `background` / `foreground` | White pages and neutral dark body text |

- Keep the original red-and-white logo unchanged.
- Keep real installation photos prominent; do not tint them to fit the palette.
- Keep primary quote buttons red across pages, including the footer.
- Use white and light blue-gray text on the dark footer, never red body text.
- Use `brand-cta` for light quote callouts and `brand-footer` for the footer.
- Avoid additional decorative colors, gradients, starbursts, and wrap illustrations in page backgrounds.
- Check text contrast, hover/focus states, and desktop/mobile layouts after color changes.
- Preserve pricing, copy, and lead-delivery behavior during visual updates.
